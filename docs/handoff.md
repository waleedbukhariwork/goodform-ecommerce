A failed send still consumes the window, so a rejected request cannot be used to probe or exhaust provider quota. The duplicate-signup message deliberately does not confirm whether an address is registered, to avoid account enumeration while still offering both real next steps. `private, no-store` is scoped to `/api/auth` and `/api/v1/auth` only, preserving the catalog GET's verified public ETag behaviour.
